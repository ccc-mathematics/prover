λ-cube 證明助手

只有變數、sort、應用、λ、Π 五種節點。∧、∨、∃、False 都用 Π 型別編碼出來,第一行的 system 決定使用 λ-cube 的哪個頂點。

點選立方體的頂點可切換系統

    

    語法與策略速查
    system λC            選擇系統:λ→ λ2 λP λω_ λP2 λω λPω_ λC
def f (x : A) : B := t      定義(可被展開);axiom c : T 公理
check t / eval t     顯示型別 / 化簡後的項與型別
theorem T (h : A) : B := by 後面接策略:
  intro x y     目標是 → 或 ∀(Church 編碼的 ∧ ∨ ∃ 也適用)
  exact t       用項直接完成
  apply t       目標吻合 t 的結論時,為前提開新目標
  assumption    目標剛好是某個假設
  have h : T [:= t]   加入新假設;沒有 := 時要先證明 T
  rfl / symm    Eq 目標:定義等價時完成 / 左右對調(需 import eq)
  rw h / rw ← h 用 h : Eq A a b 改寫目標中的 a(或 b)
  induction n with k ih   對 Nat 變數歸納,產生 base 與 step(需 import nat)
  sorry         暫時跳過(會被標記)
apply 會自動推出依賴型參數(∀);推不出時才需要自己寫,例如 apply h a
import eq / import nat   載入等式(Leibniz 編碼)/ 自然數與遞迴子,需要 λC

項:fun (x : A) => t、forall (x : A), B、A -> B、f a b、Prop、Type
也接受 λ Π ∀ →。Prop 相當於 *,Type 相當於 □。
規則 Type>Prop = 多型(System F)、Prop>Type = 依值型別、Type>Type = 型別運算子。
